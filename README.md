# RenderKit

HTML/URL → PDF and screenshot API sold as a subscription. The product lives in [`app/`](app/) (Node.js 22, Fastify, SQLite, Playwright/Chromium, Stripe). Start with [`app/README.md`](app/README.md), deploy with [`app/DEPLOY.md`](app/DEPLOY.md), launch with [`LAUNCH.md`](LAUNCH.md).

`archive/` holds two earlier experiments from this repo (a Chrome extension for site audits and a service kit for legacy PHP upgrades). They are complete but not the current direction.
