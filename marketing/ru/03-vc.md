# vc.ru — раздел «Сервисы» / «Разработка»

**Заголовок:** Запустил RenderKit: PDF и скриншоты из HTML одним запросом, с оплатой российской картой

Каждому продукту однажды нужен PDF: счёт, акт, отчёт, сертификат. Дальше два пути: библиотека (dompdf, wkhtmltopdf), которая ломает вёрстку на счёте клиента, или свой сервер с Chrome, который течёт по памяти.

RenderKit — это Chrome за обычным HTTP API. Отправляете URL или HTML, получаете PDF или PNG/JPEG/WebP. Форматы бумаги, поля, номера страниц, скриншот всей страницы, retina, ожидание селектора.

Для российских команд: оплата картой РФ через ЮKassa с чеком, серверы в России, закрывающие документы для юрлиц. Зарубежные аналоги (ApiFlash, Urlbox, DocRaptor) российской картой не оплатить.

Бесплатно 100 рендеров в месяц без карты; тарифы от 790 ₽. Документация с примерами для PHP, Laravel, Node.js, Python, Ruby, Go. Код открыт на GitHub, можно поднять у себя.
