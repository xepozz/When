# Интеграторы 1С-Битрикс и Bitrix24 — отдельный канал

Почему: тысячи интеграторов ежедневно делают счета, акты, коммерческие предложения в PDF для клиентов на Битрикс; штатные средства там слабые, а зарубежные API недоступны по оплате.

Что сделать (2–3 дня работы, могу сделать):
1. Модуль для Маркетплейса 1С-Битрикс «PDF из шаблона через RenderKit»: компонент, который берёт HTML-шаблон с плейсхолдерами заказа и возвращает PDF; настройки — API-ключ и формат.
2. Приложение для Bitrix24 (REST): кнопка «Скачать PDF» в сделке/счёте.
3. Пост в чатах интеграторов и статья на Habr «PDF-документы в Битрикс без wkhtmltopdf».

Экономика: интегратор ставит модуль десяти клиентам — десять аккаунтов на Starter/Pro.
