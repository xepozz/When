# Directory submissions (copy the block, 3–5 minutes each)

**One-liner:** RenderKit turns any URL or HTML into a PDF or screenshot with one HTTP request, rendered by headless Chrome. Free plan, paid from $9/month.

**Short description (250):** HTML/URL to PDF and PNG/JPEG/WebP screenshot API. Real Chrome rendering, headers/footers with page numbers, full-page and element screenshots, wait-for-selector, CSS injection. Nothing stored. Free 100 renders/month, from $9.

**Alternatives to (for AlternativeTo, SaaSHub):** wkhtmltopdf, dompdf, mPDF, Puppeteer, Playwright, DocRaptor, PDFShift, Urlbox, ApiFlash, ScreenshotOne, Browserless, Gotenberg, api2pdf.
