# Habr (RU)

**Заголовок:** Как я перестал чинить wkhtmltopdf и собрал API для PDF и скриншотов на одном Chromium

**Хабы:** PHP, Node.js, Разработка веб-сайтов, Программирование

**План статьи (перевести и расширить `04-article-invoice-pdf.md` + технические детали из `03-show-hn.md`):**
1. Боль: dompdf/mPDF без flexbox и grid, wkhtmltopdf на QtWebKit 2012 года, Puppeteer на кроне, который течёт.
2. Что делает Chromium правильно и почему выбор движка решает 80% проблем.
3. Print-CSS чеклист: `@page`, `break-inside`, повтор `thead`, шрифты, фон.
4. Колонтитулы с номерами страниц: где Chrome обманывает (inline font-size, поля).
5. Архитектура сервиса: Fastify, SQLite WAL, пул контекстов Playwright, очередь, таймауты, квоты атомарным UPDATE.
6. SSRF: резолв DNS главного URL и перехват всех подзапросов страницы.
7. WebP через canvas внутри страницы.
8. Что почём: бесплатно 100 рендеров, дальше от $9. Код открыт, можно поднять у себя.

В конце одна ссылка на сервис и одна на GitHub. Habr режет посты с рекламой в теле, поэтому 90% текста — техника.
